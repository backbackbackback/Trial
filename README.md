# Trial

## Starline Defense
A lightweight, browser-based space defense game inspired by classic space invaders.

### How to run (local)
1. From the repo root, start a local web server:
   ```bash
   python -m http.server 8000
   ```
2. Open the game in a browser:
   ```
   http://127.0.0.1:8000/index.html
   ```

> Tip: If the page is blank, make sure the server command is still running in the terminal.

### How to play
- Move with **Left/Right Arrow** keys.
- Fire with **Space**.
- Pause with **P**.

### Objective
Clear each wave before the fleet reaches your defense line.
